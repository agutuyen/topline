# Motion Plan Validation Checklist

- [ ] Does every transition have only ONE visual highlight?
- [ ] Is the 3D object positioned away from primary typography focal zones?
- [ ] Does the lighting maintain WCAG AA contrast (≥ 4.5:1 for body, ≥ 3.0:1 for headings)?
- [ ] Are mobile fallbacks defined for low-power GPUs?
- [ ] Is `prefers-reduced-motion` wired to pause camera choreography and lock the 3D object into a serene resting pose?
