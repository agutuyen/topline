# 6-Section Storyboard Template

| Field | Description |
|---|---|
| Section Name | Section semantic identifier (Hero, Problem, Solution, Features, Proof, CTA) |
| Core Message | Primary narrative take-away |
| 3D Object State | Transformation: start → end (translation, scale, rotation, deformation) |
| Camera State | Position (x,y,z), LookAt target, FOV |
| Lighting & Material | Key light intensity, rim light, roughness, metalness, transmission |
| ScrollTrigger Config | Trigger selector, start/end marks, scrub damping, pin behaviour |
| DOM Animation | Text entrance, opacity ramp, CTA reveal |
| Visual Highlight | Singular focal motion element |
| Readability Risk | Contrast collision with text & mitigation strategy |
| Performance Risk | GPU/fill-rate vulnerability & mitigation |
